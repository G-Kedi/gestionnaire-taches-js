# Gestionnaire de tâches

Gestionnaire de tâches réalisé en **HTML, CSS et JavaScript** dans le cadre de l'Akieni Academy.

L'application permet d'ajouter, modifier, supprimer et filtrer des tâches. Un tableau de bord permet également de suivre le nombre total de tâches, les tâches terminées et le taux de complétion.

## Fonctionnalités

- Ajouter une tâche avec un titre et une priorité
- Modifier l'état d'une tâche
- Supprimer une tâche par son identifiant
- Filtrer les tâches en cours et terminées
- Afficher le nombre total de tâches
- Afficher le nombre de tâches terminées
- Calculer le taux de complétion
- Afficher une barre de progression
- Mettre à jour les informations du tableau de bord

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Material Symbols

## JavaScript

Les tâches sont stockées dans un tableau d'objets :

```js
{
    id: 1,
    titre: "Créer la structure HTML",
    priorite: "haute",
    terminee: false
}
